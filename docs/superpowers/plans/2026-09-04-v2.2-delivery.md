# v2.2 Delivery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver opt-in explicit work packets with failure-aware complete-attempt accounting in version 2.2.0.
**Architecture:** Extend the existing Rust runtime, preserving the legacy path. A durable pre-call intent closes the lost-attempt window; a read-only ledger normalizes each attempt. An immutable user-authored plan selects bounded packets without scheduler LLM calls.
**Tech Stack:** Rust/serde/clap/fs2/sha2 and Python standard-library offline fixtures.
**Spec:** docs/superpowers/specs/2026-09-04-v2.2-delivery-design.md

## Global Constraints

- Rust 1.82 and Python 3.10 remain supported; no new third-party dependencies.
- Preserve v2.1 run readability and legacy no-plan prompt/instruction bytes.
- No global configuration, permission changes, live benchmark/provider model calls, or API spend.
- No implicit acceptance, fabricated usage, hidden failures, or savings badge.
- Runtime limits are UTF-8 bytes, not token estimates.
- Keep all work in the existing external-drive worktree; preserve unrelated changes.
