# codeunlimited 1.6 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a tested codeunlimited 1.6.0 branch that corrects accounting, project isolation, filesystem safety, diagnostics, packaging, and release provenance.

**Architecture:** Add focused boundaries rather than rewrite the CLI: `safeio` owns mutation, `Config::load_for` owns layered settings, Codex scope matching uses normalized full paths, and detector claims support a conservative union total. Existing command names remain stable while invalid inputs and failed side effects return non-zero status.

**Tech Stack:** Rust 1.82+, Clap 4, serde_json, Rayon, WalkDir, TOML, fs2, tempfile, assert_cmd, predicates, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-03-v1.6-hardening-design.md`

## Global Constraints

- Production remains offline and introduces no network client.
- Prompt/response content is never extracted, persisted, printed, or transmitted.
- Every behavior change follows red-green-refactor with real observable behavior.
- Scoped commands load the target project's config; machine-wide commands use global config.
- Mutation failures and no-data diagnostics return non-zero status.
- The branch version is exactly 1.6.0; this work creates no crate publication or Git tag.
