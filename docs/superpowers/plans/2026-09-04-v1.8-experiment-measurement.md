# codeunlimited 1.8 Experiment Measurement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a privacy-preserving experiment ledger that records exact observed token totals for bounded work windows, compares tokens per completed task, and prevents `delta` from issuing verdicts on samples below 100 requests.

**Architecture:** A new `src/experiment.rs` module owns strict state parsing, interval aggregation, comparison math, safe persistence, and rendering. `src/main.rs` exposes nested `experiment start|finish|record|compare|list` commands while reusing existing project-scoped parsers and atomic writes. Existing baseline, history, detector, and Codex-index formats remain unchanged.

**Tech Stack:** Rust 2021, Rust 1.82 MSRV, clap, serde/serde_json, chrono, existing safe I/O and parser modules, stdlib-only Python release checks.

**Spec:** `docs/superpowers/specs/2026-09-04-v1.8-experiment-measurement-design.md`

## Global Constraints

- “Exact” means sums of recognized integer counters inside `start <= ts < end`; percentages are derived presentation fields.
- Saved and JSON experiment data contain no prompts, responses, models, project paths, file paths, hostnames, findings, or raw child output.
- Records with missing timestamps are incomplete and cannot be compared.
- Comparisons require finished, non-empty, non-overlapping records with at least one completed task.
- Every comparison says `causality: observational`; one sprint per arm is low confidence.
- `delta` prints no directional verdict below 100 post-baseline requests per source.
- Existing baseline/history formats, detector formulas, and the Codex metadata index remain byte-compatible.
- Invalid, corrupt, unreadable, or symlinked experiment state fails visibly without replacement.
- Rust 1.82 remains the MSRV; add no runtime dependency.
- Every behavior change follows a witnessed RED/GREEN cycle.
- Deliver as `codex/v1.8-measurement` stacked on `codex/v1.7-performance`; do not merge, tag, or publish.
