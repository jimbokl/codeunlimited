# codeunlimited 1.7 Performance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make bounded and project-scoped audits fast on multi-gigabyte histories, cut full-audit memory, and ship a reproducible local benchmark with honest evidence wording.

**Architecture:** Pass `ScanOptions` into parsers so records are rejected before allocation, use a metadata-only Codex file index to skip proven-irrelevant unchanged files, and share repeated request strings with `Arc<str>`. Preserve the 1.6 parser wrappers for non-audit commands and expose benchmark counters only through `audit --json --scan-stats`.

**Tech Stack:** Rust 2021, Rust 1.82 MSRV, serde/serde_json, rayon, walkdir, clap, Python 3.10+ standard library, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-03-v1.7-performance-design.md`

## Global Constraints

- Never read, retain, index, print, or transmit prompt and response content.
- The index may store local file paths and normalized cwd keys; document that these can identify projects.
- Missing or corrupt cache state must not change audit results.
- Unknown layouts and uncertain timestamps are included conservatively.
- Existing non-audit commands keep their 1.6 parser and write behavior.
- `audit --no-index` performs no index read or write.
- Without `--scan-stats`, the 1.6 JSON shape remains unchanged.
- Detector formulas, union accounting, and saturation behavior do not change.
- No native dependency or database is introduced.
- Every behavior change follows a witnessed RED/GREEN test cycle.
- Delivery is a stacked PR targeting `codex/v1.6-hardening`; do not merge, tag, or publish.

- [x] **Step 3: Implement the index model**

Create `src/scan_index.rs` with serde-backed types:

```rust
pub const INDEX_FILE: &str = "codex-index-v1.json";

#[derive(Debug, Clone, PartialEq, Eq, Deserialize, Serialize)]
pub struct FileFingerprint { pub len: u64, pub modified_ns: u64 }

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct FileIndexEntry {
    pub fingerprint: FileFingerprint,
    pub cwd_keys: Vec<String>,
    pub min_ts: Option<i64>,
    pub max_ts: Option<i64>,
}

#[derive(Debug, Clone, Deserialize, Serialize)]
pub struct CodexIndex {
    pub schema_version: u64,
    pub files: BTreeMap<String, FileIndexEntry>,
}

pub enum IndexAccess { Enabled(CodexIndex), Disabled }
```

Fingerprint with file length and modified nanoseconds. Missing and invalid regular JSON yield an empty version-1 index. Symlink and other read failures disable caching. Serialize with `serde_json::to_vec_pretty` and write atomically.

- [x] **Step 4: Observe and select files**


Refresh changed/new entries, prune deleted paths, and save best-effort. Any cache warning goes to stderr without changing requests.
Increment `files_skipped_by_index` for project mismatch and
`files_skipped_by_date` for an indexed `max_ts` before the cutoff; keep the
counters disjoint when both conditions hold.

Cover append, truncation, deletion, invalid JSON rebuild, symlink refusal, and `--no-index`. Each test asserts both correct audit totals and expected `files_opened`/`files_skipped_by_index` counters. Guard only symlink creation by platform configuration.
